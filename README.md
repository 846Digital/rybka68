# Вкусная рыбка — GitHub Pages

## Размещение

Загрузите все файлы этой папки, включая `.nojekyll`, в корень репозитория.
В GitHub откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
Если основная ветка называется иначе, выберите её вместо main.
Сайт работает без сборки, npm и внешних CDN.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Текущая версия

Входной файл — index.html. Текущая версия federation-v6 — магазин рыбы.
Стили: federation.css, federation-tokens.css, federation-base.css.
Поведение и анимации: federation.js.
Тёмный графит, тяжёлая кириллическая типографика, лососевый акцент.
Слоган: «Самая вкусная рыба в Российской Федерации».
Каталог из четырёх товаров, фильтры, отдельные окна с подробными фото,
сохраняемый список заказа, идеи подачи, информация о доставке и контакты.
Роман указан как контакт для заказа. Персонального раздела и истории нет.
Плавное появление плаката, смена фильтров, переходы галереи и диалогов.
При prefers-reduced-motion движение отключено. Без JavaScript доступен
каталог и заказ по телефону.
Фото, видео, библиотеки и шрифты находятся рядом.
Неиспользуемые файлы первых версий сохранены; текущая страница их не подключает.

В галерее 17 изображений: 14 стилизованных фотокомпозиций и 3 оригинальных
изображения из материалов профиля. Новая обложка имеет прозрачный фон.
Оригинальный ролик и декоративная текстура дыма сохранены среди ресурсов
предыдущих версий, отдельного персонального раздела на странице нет.
Идеи подачи не являются готовыми наборами. Цены не указаны по просьбе владельца.

Разработчики: 846 Digital — https://846digital.github.io/846main

отправки заявки или оплаты на сайте нет.
